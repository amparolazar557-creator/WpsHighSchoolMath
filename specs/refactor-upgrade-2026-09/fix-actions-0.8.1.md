# 绘图底部操作栏修复 0.8.1

用户反馈绘图设置越来越长，插入图像需要滚到页面底部。原布局将操作按钮放在长表单中，依赖 sticky 定位；当前 Chrome 基线未复现按钮消失，WPS 内嵌环境仍待实机确认。

改为占满窗格的两行布局：上方设置和预览独立滚动，下方状态提示、更新预览、插入/更新图像按钮始终占据自己的空间。操作栏不覆盖表单；长提示最多显示三行并可滚动查看，极窄窗格按钮分行。设置区域可聚焦并用键盘滚动。共享工具窗格保留顶部切页，授权页继续独立滚动。

本次只调整布局、版本和说明；计算、授权与文档插入逻辑不变。从 0.8.0 的提交 89b6b50 开始，回退可使用该基线，图片和收藏格式未改变。
