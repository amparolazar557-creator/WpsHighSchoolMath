# 函数绘图 0.7：参数、辅助线与收藏

## 本轮范围

- 支持 a、b、c 参数及数值、滑块范围和步长；输入 ax²+bx+c 等形式，拖动时更新预览。图片显示当前参数值，保存并载入后恢复全部设置。
- 添加 x=数值、y=数值辅助线，也支持 x=a 等参数表达式；限制 20 条，超出坐标范围仍保存但不绘制。
