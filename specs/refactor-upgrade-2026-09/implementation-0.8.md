# 函数绘图 0.8：交点与切线

## 范围与约定

- 选择两条曲线或一条曲线与 x 轴，指定横坐标区间搜索交点；结果为数值近似，不承诺找出所有相切或密集交点。最多标注 20 个。
- 在一条曲线的指定 x 位置求有限斜率切线；切点位置支持 a/b/c 参数表达式。只接受定义域内部、双侧差分收敛的位置；竖直切线和单侧端点切线本轮不支持。
- 交点和切线随参数更新，结果列表显示坐标及斜率，SVG 同步显示标记。无共同定义域、重合区间、计算不稳定等情况明确反馈。
- 只保存计算设置，载入图片或收藏后重新计算，避免使用过时结果。V4 图片元数据和 V2 收藏容器承载新设置，旧格式继续可读。
- 删除或清空曲线不得把分析对象悄悄替换成另一条曲线。定义域、可见性及开闭端点参与校验。

## 实现与验证

- 新增独立数值模块，使用有界扫描、二分与残差/邻域连续性检查；切线采用逐步减小步长的双侧差分和收敛检查。
- 数值方法参考：[Boost 二分法](https://www.boost.org/doc/libs/master/libs/math/doc/html/math_toolkit/roots_noderiv/bisect.html)、[SciPy 数值导数](https://docs.scipy.org/doc/scipy/reference/generated/scipy.differentiate.derivative.html)。参考其前提与误差检查思路，本项目实现不引入这些运行时依赖。
- 回归覆盖多交点、相切、无交点、近似但不相交、极点、跳跃、重合、开闭定义域、参数更新、尖点、端点和大数。
