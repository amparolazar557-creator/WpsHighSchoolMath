# 本轮实施：函数绘图 0.6.0

用户已授权修改，并要求重点增强函数绘图。本轮交付以下范围，后续题库、原生公式及完整几何模块仍按总方案分期进行。

## 需求与验收

- 每条曲线可配置定义域、端点开闭、颜色、线型和显示状态；多行可组合分段函数。
- 提供黑白打印模式，图例与曲线一致；支持坐标点及名称标注。
- 表达式或区间有误时定位到对应行；超过曲线数量上限明确提示，不能静默丢弃。
- 新设置随图像保存；读取旧版 V1 配置，新版采用 V2，保存并重载不丢设置。
- 替换图像时先生成并验证新图，再删除旧图；新增图像不清空选中文本；失败时保留旧图。
- 原生回退入口不能静默剥离新版图像设置。
- 保持双宿主离线入口、授权规则及安装事务；本轮不更换签名密钥。

## 设计

增加纯配置模块 plot-config.js，共用校验、默认值与曲线配置。绘图模块只处理数学采样和 SVG；文档模块负责配置序列化与两种宿主的安全插入。界面负责输入、预览和错误提示。所有新脚本同步加入入口、打包白名单和离线策略。
