# 方案 B：包内静态任务窗格与全插件零 localhost 需求

状态：用户已于 2026-07-18 选择执行  
目标版本：0.4.0  
历史依据：方案一进程内原生 DLL 门禁失败；旧 0.3.3 回环助手仅作为迁移与回滚基线保留

## 1. 目标

在 WPS Writer 与 Presentation 中继续使用同一个“高中数学”Ribbon，把函数编辑器和授权中心作为插件安装目录内的静态 HTML/CSS/JavaScript 页面加载到 WPS 任务窗格。正式运行链路不得启动外部程序、监听本机端口、访问 localhost 或访问远程资源。

## 2. 范围

### 2.1 包含

- Writer/PPT 共享包内静态任务窗格管理器。
- 完整函数编辑器：多函数、坐标范围、刻度数字、网格、边框、图例、预览、插入与重新编辑。
- 正式授权中心：状态、类型、到期时间、剩余时间、机器码、粘贴激活码、QQ `982303035`、微信号 `qzt65631` 及复制按钮。
- 数学符号、函数工具、试卷工具和授权中心继续位于同一个“高中数学”Ribbon；Writer 保留试卷工具，PPT 保留适用的数学与函数工具。
- 离线授权、稳定机器码、试用期和已有激活码兼容。
- 构建、安装、升级、卸载、发布清单和安装后校验全部切换到零 localhost 载荷。

### 2.2 不包含

- 不启动或打包 `WpsHighSchoolMathEditorHost.exe`。
- 不使用 `ShellExecute`、本机 HTTP 服务、TCP 监听器、动态端口、WebSocket 或远程网页。
- 不回退方案一的 FFI、NativeX 或 COM 原生 DLL。
- 不新增云服务、账号系统、开机启动项、Windows 服务或常驻辅助进程。
- 不更改激活码签名算法、机器绑定规则和“试卷工具到期后仍可使用”的现有商业规则。

## 3. 功能需求

### R1. 包内页面硬门禁

- 当隔离探针在 Writer/PPT 点击测试按钮时，系统应使用 `Application.CreateTaskPane()` 打开探针载荷目录内的 HTML 页面。
- 当页面初始化完成时，系统应通过同一加载项的 `PluginStorage` 回写一次性 ready token；不得用 HTTP/XHR 作为就绪信号。
- 只有 Writer/PPT 均能显示页面、完成 ready 握手、关闭并重新打开，正式改造才可继续。

### R2. 全插件零 localhost

- 当用户打开插件、函数编辑器或授权中心时，系统不得创建监听端口、回环连接或外部辅助进程。
- 正式源码、构建载荷、安装包解包结果及安装目录不得包含 localhost 地址、EditorHost、回环启动器或网络兜底路径。
- 任务窗格 URL 必须是当前插件根目录下的本地静态资源；系统应拒绝远程 URL、协议相对 URL、路径越界和非白名单页面。

### R3. 函数编辑器

- 当用户点击“函数编辑器”时，系统应打开或重建包内函数编辑器任务窗格，并读取当前所选函数图像配置。
- 当用户确认插入或更新时，系统应使用现有文档事务逻辑写入图像；失败时不得删除旧图。
- 当任务窗格不可用时，系统可以提供现有四个离线快捷函数作为降级，但不得启动外部程序或访问网络。

### R4. 授权中心

- 当用户点击“授权中心”时，系统应打开包内授权页面，不再使用系统提示框作为正常授权流程。
- 授权页面应提供复制机器码、粘贴或手工输入激活码、立即激活、到期状态、复制 QQ 和复制微信号。
- 当激活失败时，系统应保留原授权状态，不记录完整激活码；取消或关闭页面不得修改状态。

### R5. Ribbon 与双宿主

- Writer 的数学符号、函数工具、试卷工具和授权中心应位于同一个“高中数学”Tab。
- PPT 的数学符号、函数工具和授权中心应位于同一个“高中数学”Tab。
- Writer 与 PPT 应加载字节一致的共享任务窗格、授权和绘图模块，并使用各自宿主角色参数。

### R6. 构建与安装

- 构建应采用精确白名单复制静态页面与共享脚本，不得编译或复制 EditorHost。
- 安装升级前应停止遗留 EditorHost，但不得再次启动它；提交成功后清理旧 runtime 和回环页面残留。
- 安装器对注入机器码的 JavaScript 必须显式使用 UTF-8，并在切换注册前完成语法、哈希和载荷集合校验。

## 4. 验收标准

1. Writer/PPT 包内页面探针均通过，页面可见且 ready token 匹配。
2. 打开函数编辑器和授权中心时无“运行外部程序”警告。
3. 运行期间无本产品辅助进程、TCP 监听器或新增回环连接。
4. Writer/PPT 函数编辑器均能预览、插入和重新编辑函数图像。
5. 授权中心能复制机器码、粘贴激活码、显示到期状态并复制 QQ/微信号。
6. Writer 的数学符号与试卷工具保持在同一 Ribbon。
7. source、staging、安装包解包结果和安装目录的零 localhost 扫描全部通过。
8. 0.3.3 旧授权在升级后仍可识别，机器码不因新建文档或宿主切换而变化。
9. 完整自动化测试、商业构建、安装后校验和双宿主实机回归全部通过后才交付 0.4.0。
